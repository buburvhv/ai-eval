# SkillLab（原 AI 辅助评估工具 ai-eval）

模型自动评估 Web 工具：配置模型网关后，大模型结合「System Prompt/系统提示词」与「Skill 评估标准」对输入信息进行自动评估，并支持人工点赞/点踩标注，数据存入本地 SQLite。

除纯文本 Skill（.md 评分标准）外，支持**复杂 Skill 包**（SKILL.md + scripts/ 的 zip 包）：评估时模型可通过 `[INVOKE:脚本名]` 协议调用包内脚本、读取执行结果后再给出报告，实现带本地计算/数据处理能力的评估。


## 功能特性

- **基于 Skill 决策的自动评估**：上传 .md/.txt 评估标准文件（SKILL.md），选择 System Prompt 与模型后自动逐轮评估。输出格式由 Skill 自行定义——前端通用展示：Markdown 表格渲染成表格、JSON 格式化展示、其余正常输出，不再绑定任何特定 Skill 的固定结构。
- **Skill 可选（纯对话模式）**：不选 Skill 即普通 AI 对话——System Prompt 直接作为 system 指令、输入原样作为对话消息；选了 Skill 才走评估协议。
- **多轮上下文（可选）**：上下文栏「🔄 多轮对话」开关（默认开）。开启后，同一会话内本轮运行可参考此前最近 5 轮已完成的输入与结果（单轮超 4000 字自动截断），适合追问与连续处理；关闭则每轮相互独立。消息流中每条输入标注会话内轮次，并在上下文开始生效处显示分割线。
- **复杂 Skill 包（带脚本）**：上传 zip 包（SKILL.md + scripts/），模型评估中可调用包内白名单脚本（.py/.bat/.cmd），执行结果回喂模型继续推理；每条评估记录保存完整脚本执行轨迹（脚本名、exit 码、耗时、stdout/stderr）。脚本执行前需明确授权（每次评估单独确认，或设置页长期授权）。
- **评估状态闭环**：发送即创建会话（后端先落库占位，模型返回后更新结果），失败/停止都有明确终态和错误原因；可「停止」当前评估，可把历史内容「带入输入框重评」。
- **会话历史**：左侧按会话分组，标题取自首条输入，支持重命名、删除；刷新页面自动恢复上次会话。
- **人工标注**：每条结论可标注「正确 / 不正确」（再点一次可撤销、点另一项可切换），实时写入服务端 SQLite，支持一键导出 CSV（含状态/错误信息，带 BOM，Excel 打开不乱码）。
- **模型网关探测**：通用 OpenAI 兼容接口，自动探测常用端口，兼容厂内网关、vLLM、Ollama 等。
- **多用户隔离**：默认配置（作者预置）对所有用户只读；用户自定义模型配置仅存本浏览器 localStorage。

## 启动

```bash
cd ai-eval
pip install -r requirements.txt
python server.py
```

打开浏览器访问 http://127.0.0.1:8790

> 监听 `0.0.0.0:8790`：本机开发用 127.0.0.1 访问，部署到内网 / POPO 时其他机器可通过服务器 IP:8790 访问。
> 如需只允许本机访问（尤其启用了复杂 Skill 包脚本执行时），启动前设置 `AI_EVAL_HOST=127.0.0.1`。


## 使用流程

1. **模型配置**：设置页填写网关 Base URL 与 API Key（可选端口），保存时自动探测 `/models` 接口，下拉选择模型后可用「测试调用」验证连通性。
   - 支持 `http://host`、`http://host:port` 两种写法；不填端口时自动探测常用端口。
   - 兼容 OpenAI 接口的网关均可接入（厂内网关、vLLM、Ollama 等）。
2. **System Prompt**：填写名称 + 内容保存，之后从主页面下拉直接载入复用。选了 Skill 时作为被评估对象的画像；纯对话时直接作为 system 指令。
3. **评估标准（Skill）**：上传 skill 文件（.md/.txt），自定义命名保存，主页面下拉选择。
4. **复杂 Skill 包（可选）**：设置页「复杂 Skill 包」卡上传 zip 包并命名。包结构：

   ```
   包.zip
   ├── SKILL.md          # YAML frontmatter（name/description/scripts）+ 评分标准正文
   └── scripts/
       └── tool.py       # frontmatter 声明的脚本（.py/.bat/.cmd）
   ```

   SKILL.md frontmatter 示例：

   ```yaml
   ---
   name: my-skill
   description: 说明这个包做什么评估
   scripts:
     - name: tool            # 模型用 [INVOKE:tool 参数...] 调用
       path: scripts/tool.py
       description: 脚本做什么
       timeout: 60           # 秒，上限 300
   ---
   ```

   脚本从 stdin 收到 JSON 上下文（含 `input_text` 待评估文本），stdout 输出会回喂给模型。首次用该包评估时网页会弹确认框列出全部脚本，同意本次才执行；也可在设置页「授权脚本」长期放行（授权前列表带红色「脚本未授权」标记）。报告卡展开「详细评分」可看到「脚本执行轨迹」。
5. **运行**：选择 Skill（可选——不选即纯 AI 对话）、模型（必选）、System Prompt（可选），输入内容后发送。同一会话内连续发送即多轮交互（上下文栏「🔄 多轮对话」开关控制，模型可参考此前最近 5 轮）。运行中发送按钮变为「■ 停止」，可随时中止；超过 5 分钟会提示输出较慢。
6. **反馈**：对评估结果标注「正确 / 不正确」，标注自动保存到 SQLite，可导出 CSV。

## 安全说明（复杂 Skill 包）

- 包上传有完整校验：zip 大小/条目数/解压总量上限（防 zip 炸弹）、路径合法性（防 zip-slip 越界写入）、frontmatter 声明的脚本必须存在且后缀受限。
- 模型只能调用 frontmatter 声明白名单里的脚本，待评估文本中出现的 `[INVOKE:...]` 字样只会被当作被评估材料，不会执行。
- 脚本以当前用户权限在本机运行：**请只上传来源可信的 Skill 包**。执行有单脚本超时（默认 60s，上限 300s）与总调用次数（5 次）限制。
- 服务绑定 `0.0.0.0` 时局域网内其他机器可触发本机脚本执行，介意可设 `AI_EVAL_HOST=127.0.0.1`。

## 数据存储

- `data.db`：SQLite 数据库（模型配置、System Prompt、Skill、评估记录及反馈、脚本执行轨迹）。可用环境变量 `AI_EVAL_DB` 指定路径。
- `skills/`：上传的 Skill 源文件与解压后的 Skill 包目录。


## 前端说明

- 主界面：上下文栏（Skill / System Prompt / 模型 / 多轮对话开关）+ 消息流（单列运行结果卡，轮次标注 + 上下文生效分割线，结果卡可一键复制输出）+ 发送区（运行中变为停止按钮）。支持浅色 / 深色主题（左下角切换，跟随系统偏好）。
- 设置页：模型配置（默认可直接修改 URL/Key，可新增/编辑/删除自有配置，仅存本浏览器）、System Prompt 管理、Skill 管理、复杂 Skill 包管理、数据导出。
- 评估中提示：初始「模型正在按 Skill 标准逐轮评估，请稍候…」，超过 300 秒追加「评估已超过 5 分钟，输出较慢」。
