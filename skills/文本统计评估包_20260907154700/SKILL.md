# 文本统计辅助评估标准

评估开始前，必须先用 [INVOKE:analyze] 调用 analyze 脚本，获取待评估文本的客观统计结果，
然后结合统计结果按以下六个维度打分（每维满分 2 分，总计 12 分）：

- 意图识别：是否快速、正确识别用户意图
- 内容价值：内容是否有信息量、是否空泛（参考脚本给出的字数/高频词，空泛或复读应扣分）
- 情绪价值：是否照顾用户感受、共情到位
- 真人感：语言是否口语自然、不像背书（参考句长与问候语检测）
- 人设匹配度：是否符合设定人设
- 自然延展：对话是否自然推进、不机械

统计结果只是辅助证据，不要照抄进报告。最终输出必须是不含 INVOKE 的纯 JSON 报告。
